# Layout de Bodega

Proyecto web React + Vite preparado desde el prototipo de Copilot.

## Desarrollo local
```bash
npm install
npm run dev
```

## Compilar
```bash
npm run build
```

## Datos
Esta primera version guarda cambios en localStorage del navegador. Esto da persistencia en un mismo dispositivo, pero todavia no sincroniza PC y telefono. La siguiente fase debe conectar una base central.

## Despliegue
Subir el proyecto a un repositorio Git y conectarlo a Vercel.
